# Movie Website

Movie Website — pet-проект, который я сделал как публичный пример своего подхода к фронт-разработке.

Большая часть моего опыта связана с коммерческими проектами, код которых нельзя показать публично. Поэтому я решил сделать отдельный проект, где можно посмотреть, как я работаю с React и TypeScript, организую структуру приложения, взаимодействую с внешним API, управляю серверным состоянием, пишу переиспользуемые компоненты и покрываю их тестами.

Это не попытка сделать полноценный аналог онлайн-кинотеатра. Основная цель проекта — на реальном примере показать используемый мной стек и подход к разработке современного фронт-приложения.

## О проекте

Кино-сервис на React для просмотра подборок фильмов и сериалов, поиска по базе TMDB и открытия детальной страницы медиаконтента.

Данные приложение получает через TMDB API. Для работы с серверным состоянием используется TanStack Query, API-клиент генерируется с помощью Orval, а отдельные UI-компоненты вынесены в Storybook.

## Возможности

* Главная страница с промо-блоком и каталогом фильмов и сериалов по жанрам
* Поиск фильмов и сериалов через модальное окно с debounce
* Детальная страница фильма или сериала
* Отображение рейтинга, жанров, длительности, года выхода и описания
* Рецензии и дополнительная информация о медиаконтенте
* Skeleton-состояния во время загрузки
* Работа с TMDB API через отдельный слой адаптеров
* Кэширование и управление серверным состоянием через TanStack Query
* Переиспользуемые UI-компоненты
* Storybook для разработки и демонстрации компонентов
* Unit и component-тесты на Vitest и Testing Library

## Структура проекта

```text
src/
  api/          API-адаптеры поверх сгенерированного клиента
  components/   общие компоненты приложения
  generated/    код, сгенерированный Orval
  hooks/        переиспользуемые React-хуки
  pages/        страницы приложения
  shared/       общие типы, константы, роутинг и утилиты
  stories/      Storybook-примеры
  tests/        тестовые helpers и setup
```

## Переменные окружения

Для работы с TMDB API необходим API-ключ.

Создай файл `.env` в корне проекта:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key
```

Получить ключ можно в личном кабинете TMDB.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```

Открыть production-preview:

```bash
npm run preview
```

## Генерация API-клиента

Проект использует Orval для генерации API-клиента для TMDB.

```bash
npm run generate:api
```

Сгенерированные файлы находятся в `src/generated/`.

## Анализ сборки

```bash
npm run analyze
```

Команда собирает проект с конфигурацией `vite.sonda.config.ts` и позволяет анализировать размер и состав чанков.

## Деплой

Проект настроен для деплоя на Netlify через `netlify.toml`.

Для корректной работы SPA-маршрутизации настроен fallback на `index.html`.

Перед деплоем необходимо добавить `VITE_TMDB_API_KEY` в переменные окружения проекта на Netlify.
